# Портфолио DK

Готовый статический сайт на HTML, CSS и JavaScript. В папке `dist` лежат главная, каталог, пять кейсов, UI-кит, изображения, шрифты, иконки и видео. Для работы сайта достаточно статического хостинга.

## Публикация на Vercel

1. Распакуй ZIP. Добавь `vercel.json`, `README.md` и папку `dist` в корень репозитория GitHub. Можно использовать приватный репозиторий.
2. В Vercel выбери **Add New → Project**, импортируй этот репозиторий и нажми **Deploy**. В качестве корня проекта используй папку с `vercel.json`. Конфигурация в архиве выбирает **Other** и публикует `dist` как есть.
3. После публикации открой основной **Production Domain** из раздела **Domains** в приватном окне браузера. Если Vercel просит войти, проверь настройки **Deployment Protection** для production-домена.

Если Node.js уже установлен, можно опубликовать сайт из терминала. Открой папку с `vercel.json` и выполни:

```bash
npx vercel --prod
```

При первом запуске Vercel предложит войти и выбрать или создать проект.

[Документация Vercel по публикации](https://vercel.com/docs/deployments) · [Настройки доступа](https://vercel.com/docs/deployment-protection)

## Проверка на компьютере

Из папки с `vercel.json` запусти обычный HTTP-сервер. Если установлен Python 3:

```bash
python3 -m http.server 4173 --directory dist
```

На Windows, если Python запускается командой `py`, замени `python3` на `py -3`. Открой `http://localhost:4173/`.

## Страницы

- `/` — главная.
- `/projects/` — каталог и переходы к пяти кейсам.
- `/style-guide/` — интерактивный UI-кит. Его можно открыть по прямой ссылке.

Форма «Написать мне» подготавливает письмо и открывает почтовое приложение посетителя. Для этого в браузере должно быть настроено приложение для почты; данные формы обрабатываются в браузере. Внешние ссылки открывают Behance, Pinterest, Telegram и макеты Figma. Доступ к макетам зависит от их настроек в Figma.

Archivo Black и Wix Madefor Display поставляются с файлами лицензий в `dist/assets`. Handil Pro Medium подключён из предоставленного файла. Перед публичной публикацией сверь разрешение на веб-встраивание с условиями своей лицензии. [Handil Pro от Alifinart Studio](https://alifinart.com/product/handil-pro/)
